# Team Follow Up AI plugins

Official plugins that connect [Team Follow Up AI](https://teamfollowup.ai) to AI coding agents and assistants.

| Plugin | What it does |
| --- | --- |
| [`tfuai`](plugins/tfuai) | Runs Team Follow Up AI through the official hosted MCP server at `https://api.teamfollowup.ai/api/mcp` |

Setup, sign-in and safety notes are in the [plugin README](plugins/tfuai/README.md).
